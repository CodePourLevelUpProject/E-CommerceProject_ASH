## <span style="color: #2E86AB">1. 메인 화면 및 기본 기능</span>
### <span style="color: #A23B72">회원가입</span>
- 카카오, 구글, 네이버 OAuth 인증 방식 회원가입 지원
    - 외부 서비스 연동 문제
        - OAuth 제공자 API 호출 시 네트워크 오류
        - API 호출 시 전달되는 필수 파라미터 잘못된 경우
        - access token, ID token 조회 실패
    - 리다이렉트 문제
        - 이미 가입된 회원: 소셜 로그인을 시도한 사용자가 이미 데이터베이스에 존재하는 회원임에도 불구하고, 메인 페이지가 아닌 전화번호 입력 페이지 등 다른 페이지로 잘못 리다이렉트되는 경우.
        - 전화번호 없는 회원: 소셜 로그인을 통해 성공적으로 인증되었지만, 전화번호 정보가 없는 회원일 경우 전화번호 입력 페이지가 아닌 다른 페이지로 잘못 리다이렉트되는 경우.
- 이메일 소셜 계정에서 자동 수집
    - 데이터 연동 문제
        - 이메일 주소 조회 실패
        - 기존 회원과 로그인으로 접근한 사용자 매칭 못할 경우
- 이미 가입된 회원일 경우 메인페이지 리다이렉트
- 전화번호 없는 회원일 경우 전화번호 입력 페이지 이동
- 휴대폰 번호 필수 입력
    - "010-1234-1234" 형태로 보여줌
    - '-' 입력 없어도 UI에서 자동 삽입
    - 서버에선 "01012341234"로 저장
    - 숫자 아닌 문자, 공백, 길이 초과 시 틀린 부분 커서 이동 및 메시지 출력
    - 이미 저장된 번호일 경우 "이미 가입된 회원입니다" 메시지 모달창 띄운 후 로그인 페이지 이동
    - 유효성 검사 실패
        - 공백 포함되거나, 누락
        - 숫자 이외 문자, 특수문자 포함
        - 숫자 11자리 아닌 경우
        - 유효하지 않은 형식 (010 시작하지 않는 경우)
    - 중복 번호 가입 시도
        - 중복된 번호인데 판단 못한 경우
- 전화번호 인증
    - 타인 전화번호 도용 방지
    - 인증번호 미확인 상태: 전화번호는 입력했지만, SMS 인증번호를 확인하지 않은 상태에서 회원가입이 완료되는 경우.
    - 인증번호 재사용: 한 번 사용된 인증번호가 유효 시간 내에 다시 사용될 수 있는 경우.
    - 무차별 대입 공격(Brute-force attack): 일정 횟수 이상 인증번호 입력 실패 시 추가 인증 요청을 제한하는 로직이 없는 경우.
- 개인정보처리방침 및 이용약관 동의 필수
    - 필수 동의 누락
- 최초 가입 시 포인트 5000 지급
    - 최초 가입 시점 식별 miss로 인한 중복 지급, 누락
    - 지급은 실패했는데 성공처리 되는 경우
### <span style="color: #A23B72">로그인</span>
- JWT + Cookie 방식
    - JWT 유효성 검증 실패
        - 서명 위조된 JWT 수신
        - 만료된 JWT 수신
        - JWT 발급자, 수신자 등의 Claim 정보가 유효하지 않을 경우
    - 쿠키 관련 문제
        - 쿠키에 JWT 누락, 올바르게 저장되지 않은 경우
        - 서버에 저장된 JWT 정보와 쿠키의 JWT 정보 불일치
        - 보안 정책 (HttpOnly, Secure, SameSite) 등의 속성이 올바르게 설정되지 않은 쿠키 수신
- OAuth 인증 방식 회원가입 지원
    - 외부 서비스 연동 문제
        - OAuth 제공자 API 호출 시 네트워크 오류
        - API 호출 시 전달되는 필수 파라미터 잘못된 경우
        - access token, ID token 조회 실패
    - 리다이렉트 문제
        - 전화번호 없는 회원: 소셜 로그인을 통해 성공적으로 인증되었지만, 전화번호 정보가 없는 회원일 경우 전화번호 입력 페이지가 아닌 다른 페이지로 잘못 리다이렉트되는 경우.
### <span style="color: #A23B72">이벤트/상품 랭킹</span>
- 인기 상품 TOP 10 (기준: 판매량)
    - 판매량 집계 기준: 최근 30일 기준 실제 결제 완료된 주문 건수
    - 실시간 업데이트: 매 시간마다 배치 작업으로 랭킹 갱신
    - 동일 판매량일 경우 최신 등록 상품 우선 노출
    - 품절 상품은 랭킹에서 제외
    - 데이터 집계 오류
        - <span style="color: #F24236">판매량 집계 시 중복 계산되는 경우</span>
        - <span style="color: #F24236">취소/환불된 주문이 판매량에 반영되지 않는 경우</span>
        - <span style="color: #F24236">배치 작업 실패로 인한 랭킹 업데이트 누락</span>
        - <span style="color: #F24236">서버 시간대 불일치로 인한 집계 기간 오차</span>
    - 캐시 관련 문제
        - <span style="color: #F24236">랭킹 캐시 만료 시점과 실제 데이터 불일치</span>
        - <span style="color: #F24236">캐시 무효화 실패로 인한 구 데이터 노출</span>
- 베스트 상품 (기준: 리뷰 수)
    - 리뷰 집계 기준: 구매 확정된 주문에 대한 리뷰만 집계
    - 평점 4.0 이상인 상품만 베스트 상품 대상
    - 최소 리뷰 10개 이상인 상품만 노출
    - 리뷰 집계 오류
        - 삭제된 리뷰가 집계에서 제외되지 않는 경우
        - 허위 리뷰(봇, 어뷰징) 필터링 실패
        - 리뷰 수와 평점 계산 로직 불일치
- 할인 상품 등 이벤트
    - 할인율 10% 이상인 상품만 이벤트 상품으로 분류
    - 이벤트 기간 설정: 시작일시/종료일시 정확한 관리
    - 할인가 자동 계산: 원가 × (100 - 할인율) / 100
    - 재고 소진 시 이벤트에서 자동 제외
    - 이벤트 관리 오류
        - 이벤트 기간 만료 후에도 할인가 적용되는 경우
        - 할인율 계산 오류로 인한 잘못된 가격 표시
        - 이벤트 상품 재고와 실제 재고 불일치
        - 동시 접속자 증가로 인한 이벤트 페이지 로딩 지연
### <span style="color: #A23B72">광고 배너</span>
- 외주사 지급 비용에 따라 우선순위별 차등 표출
    - 우선순위 점수 계산: 광고비 × 가중치 + 클릭률 × 가중치
    - 점수 높은 순으로 상위 노출 위치 배정
    - 동일 점수일 경우 등록 순서대로 노출
    - 광고 예산 소진 시 자동으로 노출 중단
    - 우선순위 계산 오류
        - 광고비 정산 오류로 인한 잘못된 우선순위 적용
        - 클릭률 집계 오류 (봇 클릭, 중복 클릭 포함)
        - 우선순위 업데이트 배치 작업 실패
- 최대 5개까지 노출
    - 활성화된 광고 중 상위 5개만 메인 화면에 표시
    - 광고 이미지 크기: 1200×400px (PC), 800×300px (모바일)
    - 광고 클릭 시 외부 링크 또는 상품 상세 페이지로 이동
    - 광고 노출/클릭 통계 실시간 수집
    - 광고 표시 오류
        - 이미지 로딩 실패로 인한 빈 배너 노출
        - 링크 URL 오류로 인한 404 페이지 이동
        - 광고 승인 상태 확인 누락으로 미승인 광고 노출
        - 모바일/PC 반응형 이미지 크기 오류
    - 통계 수집 오류
        - 광고 노출 수 중복 집계
        - 클릭 이벤트 누락으로 인한 통계 오차
        - 통계 데이터 저장 실패
### <span style="color: #A23B72">상품 카테고리 선택 메뉴</span>
- 대분류 → 소분류 2단계 카테고리 구조
    - 대분류: 강아지용품, 고양이용품
    - 소분류: 강아지용품 → 사료, 간식, 장난감, 의류, 목줄/리드줄, 살림용품, 건강관리 등
    - 소분류: 고양이용품 → 사료, 간식, 장난감, 의류, 목걸이, 모래, 건강관리 등
- 모바일에서는 아코디언 형태로 펼침/접힘 기능
    - 카테고리 구조 오류
        - 대분류-소분류 연결 관계 오류
        - 카테고리 삭제 시 하위 카테고리 처리 누락
        - 카테고리명 중복으로 인한 혼동
    - 상품 수 집계 오류
        - 품절 상품이 집계에 포함되는 경우
        - 비활성화된 상품이 집계에 포함되는 경우
        - 카테고리 변경된 상품의 집계 반영 지연
    - UI/UX 관련 오류
        - 메가메뉴 표시 위치 오류 (화면 밖으로 벗어남)
        - 모바일 아코디언 동작 오류
        - 카테고리 로딩 지연으로 인한 빈 메뉴 표시
        - 터치 이벤트와 마우스 이벤트 충돌

## <span style="color: #2E86AB">2. 상품 카탈로그</span>

- **<span style="color: #F18F01">상품 검색/필터링/정렬</span>**
    - 키워드 검색 (초기: DB 기반, 추후 Elasticsearch)
        - 검색 결과 없을 시 연관 상품 추천
        - 검색 성능 오류
            - DB 인덱스 누락으로 인한 검색 속도 저하
            - 검색어 특수문자 처리 오류
            - 대소문자 구분 오류로 인한 검색 결과 누락
            - 검색 쿼리 최적화 부족으로 인한 타임아웃
    - 브랜드/가격/평점/재고유무 필터
        - 다중 필터 조합 지원 (AND/OR 조건)
        - 가격 범위 슬라이더 UI (최소/최대 가격 설정)
        - 평점 4.0 이상, 3.0 이상 등 구간별 필터
        - 재고 있음/품절 포함 옵션
        - 필터링 오류
            - 필터 조건 조합 시 결과 집합 오류
            - 가격 범위 계산 오류 (할인가 미반영)
            - 평점 집계 오류로 인한 잘못된 필터링
            - 재고 상태 실시간 반영 지연
    - 가격↑↓, 인기순, 최신순 정렬
        - 기본 정렬: 인기순 (판매량 + 조회수 가중치)
        - 가격 정렬 시 할인가 기준으로 정렬
        - 최신순: 상품 등록일 기준
        - 정렬 오류
            - 정렬 기준 불일치로 인한 결과 순서 오류
            - 페이지네이션과 정렬 조합 시 중복/누락
            - 정렬 성능 저하로 인한 응답 지연
- **<span style="color: #F18F01">상품 상세 조회</span>**
    - 대표 이미지, 옵션(색상/사이즈), 상세 설명, 재고, 리뷰 요약
        - 이미지 확대/축소 기능 (줌인/줌아웃)
        - 옵션별 재고 실시간 표시
        - 상품 상세 정보 탭 구성 (상세정보/리뷰/Q&A/배송정보)
        - 상품 조회 오류
            - 이미지 로딩 실패로 인한 빈 이미지 표시
            - 옵션 조합별 재고 정보 불일치
            - 상품 정보 캐시와 실제 데이터 불일치
            - 상품 상세 페이지 로딩 타임아웃
    - 메인 이미지 + 썸네일
        - 썸네일 클릭 시 메인 이미지 변경
        - 이미지 lazy loading 적용
        - 이미지 압축 최적화 (WebP 포맷 지원)
        - 이미지 관련 오류
            - 썸네일과 원본 이미지 불일치
            - 이미지 CDN 장애로 인한 로딩 실패
            - 모바일 환경에서 이미지 크기 최적화 오류
    - 옵션 선택 드롭다운
        - 색상/사이즈 조합별 재고 확인
        - 품절 옵션은 비활성화 처리
        - 옵션 선택 시 가격 자동 업데이트
        - 옵션 관련 오류
            - 옵션 조합 유효성 검증 오류
            - 품절 옵션 선택 가능한 상태로 표시
            - 옵션별 추가 금액 계산 오류
    - 수량 선택 후 '장바구니 담기', '바로 구매' 버튼
        - 최대 구매 가능 수량 제한 (재고 기준)
        - 수량 증감 버튼 (+/-) 제공
        - 장바구니 담기 시 중복 상품 수량 합산
        - 구매 관련 오류
            - 재고보다 많은 수량 선택 가능
            - 장바구니 담기 시 세션 만료 오류
            - 동시 구매 시도로 인한 재고 부족
- **<span style="color: #F18F01">리뷰/평점</span>**
    - 구매 완료자만 작성 가능
        - 주문 상태가 '배송완료'인 상품만 리뷰 작성 권한
        - 구매 확정 후 30일 이내 리뷰 작성 가능
        - 상품별 1회만 리뷰 작성 가능
        - 리뷰 작성 시 포인트 100점 지급
        - 리뷰 권한 오류
            - 구매하지 않은 상품에 리뷰 작성 가능
            - 중복 리뷰 작성 방지 로직 오류
            - 리뷰 작성 기간 만료 확인 오류
    - 사진 첨부, 별점(1~5), 댓글
        - 사진 최대 5장까지 첨부 가능
        - 사진 파일 크기 제한 (5MB 이하)

## <span style="color: #2E86AB">4. 주문</span>

- 장바구니 선택 상품 재고 차감

    - 재고 부족 시 주문 불가 처리 및 알림
    - 동시 주문 처리를 위한 재고 락(Lock) 적용
    - 주문 실패 시 차감된 재고 자동 복구
    - 재고 관리 오류
        - 동시 주문으로 인한 재고 마이너스 발생
        - 재고 차감 후 결제 실패 시 복구 누락
        - 재고 락 해제 실패로 인한 데드락
        - 옵션별 재고 차감 로직 오류
- 선택 상품 가격 Total
    - 상품 금액 + 배송비 + 추가 옵션비 합계
    - 할인 쿠폰, 포인트 사용액 차감
    - 부가세 포함 최종 결제 금액 표시
    - 가격 계산 오류
        - 할인 적용 순서 오류로 인한 금액 차이
        - 부가세 계산 오류 (소수점 처리)
        - 배송비 중복 계산
- **<span style="color: #F18F01">주문 흐름</span>**
    - 장바구니 → 주문하기 클릭
        - 선택된 상품만 주문 진행
        - 품절/판매중단 상품 자동 제외
        - 주문 가능 최소 금액 확인 (1,000원 이상)
        - 주문 흐름 오류
            - 품절 상품이 주문 목록에 포함
            - 주문 최소 금액 미달 시에도 진행 가능
            - 세션 만료로 인한 주문 정보 손실
    - 주소 선택/등록 → 배송비 계산
        - 기본 배송지 자동 선택
        - 새 배송지 등록 시 주소 검색 API 연동
        - 배송 불가 지역 확인 및 안내
        - 배송지별 배송비 실시간 계산
        - 배송 관련 오류
            - 잘못된 주소 형식 입력 허용
            - 배송 불가 지역에도 주문 진행
            - 배송비 계산 API 연동 실패
    - 결제 수단 선택 (신용카드, 가상계좌, 페이 등)
        - 결제 수단별 수수료 안내
        - 무이자 할부 옵션 제공
        - 간편결제 (카카오페이, 네이버페이) 지원
        - 결제 수단 오류
            - 결제 모듈 연동 실패
            - 결제 승인 후 주문 생성 실패
            - 결제 취소 시 환불 처리 지연
- **<span style="color: #F18F01">환불/취소</span>**
    - 주문 상태별 취소 가능성 제어 (A: 결제 전, B: 배송 전)
        - 결제 완료 후 30분 이내: 무조건 취소 가능
        - 배송 준비 중: 고객센터 문의 후 취소
        - 배송 시작 후: 취소 불가, 반품/교환만 가능
        - 취소/환불 오류
            - 취소 불가 상태에서 취소 처리
            - 부분 취소 시 배송비 처리 오류
            - 환불 금액 계산 오류 (쿠폰/포인트 복구)
    - 환불 처리 시 재고 복구
        - 취소된 상품 수량만큼 재고 자동 증가
        - 옵션별 재고 정확한 복구
        - 재고 복구 실패 시 관리자 알림
        - 재고 복구 오류
            - 재고 복구 중복 처리
            - 옵션별 재고 복구 누락
            - 재고 복구 실패 시 알림 누락

## <span style="color: #2E86AB">10. 비기능적 요구사항</span>

- 로그인 권한(유저, 어드민)
    - 어드민은 관리자 툴 접근 가능
        - 권한 관리 오류
            - 권한 없는 사용자의 관리자 기능 접근
            - 권한 변경 시 세션 정보 불일치
            - 관리자 로그 기록 누락
- **<span style="color: #F18F01">성능:</span>** 상품 조회 200ms 이내, 주문 처리 1초 이내
    - 데이터베이스 쿼리 최적화 및 인덱스 적용
    - CDN을 통한 이미지/정적 파일 캐싱
    - 성능 모니터링 및 알림 시스템
    - 성능 관련 오류
        - 데이터베이스 커넥션 풀 부족
        - 캐시 히트율 저하로 인한 성능 저하
        - 메모리 누수로 인한 서버 다운
        - 응답 시간 초과로 인한 타임아웃
- **<span style="color: #F18F01">안정성:</span>** 재고 동시성 100TPS 이상
    - 락을 이용한 재고 동시성 제어
    - 데이터베이스 트랜잭션 격리 수준 관리
    - 서킷 브레이커 패턴으로 장애 전파 방지
    - 안정성 관련 오류
        - 동시성 제어 실패로 인한 데이터 불일치
        - 트랜잭션 데드락 발생
        - 서킷 브레이커 오작동
- **<span style="color: #F18F01">보안:</span>** TLS 1.2+, OWASP Top10 방어(선택), JWT 만료/리프레시
    - HTTPS 강제 적용 및 HSTS 헤더 설정
    - SQL 인젝션, XSS, CSRF 공격 방어
    - JWT 토큰 만료 시간 관리 및 리프레시 토큰
    - 개인정보 암호화 저장 (AES-256)
    - 보안 관련 오류
        - SSL 인증서 만료
        - JWT 토큰 탈취 및 재사용
        - 개인정보 평문 저장
        - 보안 헤더 누락
- **<span style="color: #F18F01">확장성:</span>** 마이크로서비스 이관 준비 (Outbox Pattern 적용)
    - 도메인별 서비스 분리 설계
    - 이벤트 기반 아키텍처 적용
    - API Gateway를 통한 서비스 라우팅
    - 확장성 관련 오류
        - 서비스 간 의존성 순환 참조
        - 이벤트 발행/구독 실패
        - API Gateway 단일 장애점
- **<span style="color: #F18F01">개인화 추천:</span>** ML 기반 상품 추천 엔진
    - 사용자 행동 데이터 수집 및 분석
    - 협업 필터링 및 콘텐츠 기반 필터링
    - A/B 테스트를 통한 추천 성능 개선
    - 추천 시스템 오류
        - 추천 모델 학습 실패
        - 사용자 데이터 부족으로 인한 콜드 스타트
        - 추천 결과 편향성 문제
