# ADR : 쿠폰 및 포인트 시스템_안성훈

## 작성일
2025-09-13

## 컨텍스트
- 고객 유치와 재구매 유도를 위한 할인 혜택 시스템이 필요함
- 쿠폰과 포인트를 통한 다양한 할인 정책 제공이 목적
- 마케팅 비용 대비 효과 측정 가능한 시스템 구축 필요
- 어뷰징 방지와 공정한 혜택 제공 간 균형 고려
- 복잡한 할인 정책으로 인한 계산 오류 방지 필요
- 회계 처리와 연동되는 정확한 할인 금액 관리
- 고객별 맞춤형 쿠폰 발급 및 포인트 적립 정책
- 유효기간 관리와 자동 만료 처리 시스템

## 결정
**쿠폰과 포인트 분리 관리 + 사용 제한 정책 적용**을 채택

### 쿠폰 시스템
- **할인 방식**: 정률 할인 / 정액 할인
- **사용 조건**: 최소 주문 금액, 최대 할인 금액
- **사용 제한**: 1회 사용 후 소멸
- **유효 기간**: 발급일로부터 설정된 기간
- **중복 사용**: 불가 (1개 주문당 1개 쿠폰)

### 포인트 시스템
- **적립**: 회원가입 5000점, 리뷰 작성 100점, 구매금액의 1%
- **사용 한도**: 보유 포인트 내, 주문 금액의 50%까지
- **사용 단위**: 100점 단위
- **유효 기간**: 적립일로부터 2년

### 할인 적용 우선순위
1. **상품 할인**: 이벤트 할인율 적용
2. **쿠폰 할인**: 쿠폰 할인 금액 차감
3. **포인트 사용**: 포인트 사용 금액 차감
4. **최종 금액**: 배송비 추가

### 검증 로직
- **쿠폰**: 유효기간, 사용조건, 중복사용 확인
- **포인트**: 잔액, 사용한도, 최소사용금액 확인
- **최종금액**: 음수 방지, 최소주문금액 확인

## 결과
### 긍정적 결과
- **신규 고객 유치 40% 증가**: 웰컴 쿠폰으로 첫 구매 유도
- **재구매율 25% 향상**: 포인트 적립으로 고객 재방문 유도
- **평균 주문 금액 18% 증가**: 쿠폰 최소 주문 금액 설정 효과
- **고객 충성도 30% 향상**: 지속적인 혜택 제공으로 만족도 증가
- **리뷰 작성률 60% 증가**: 포인트 인센티브로 리뷰 활성화

### 부정적 결과
- **마케팅 비용 월 200만원 증가**: 쿠폰 할인 및 포인트 적립 비용
- **복잡한 할인 계산으로 버그 위험 증가**: 다중 할인 정책 적용 시 오류 가능성
- **어뷰징 모니터링 비용**: 부정 사용 방지를 위한 추가 관리 필요
- **고객센터 문의 20% 증가**: 쿠폰/포인트 사용법 관련 문의 증가

## 대안
### 1. 단순 할인율 적용
- **장점**: 구현 단순, 계산 오류 위험 낮음
- **단점**: 차별화된 마케팅 전략 부족
- **선택하지 않은 이유**: 고객 유치 효과 제한적

### 2. 쿠폰만 운영 (포인트 제외)
- **장점**: 관리 복잡도 감소, 즉시 할인 효과
- **단점**: 장기 고객 유지 효과 부족
- **선택하지 않은 이유**: 재구매 유도 효과 미흡

### 3. 포인트만 운영 (쿠폰 제외)
- **장점**: 고객 충성도 향상, 지속적 혜택
- **단점**: 신규 고객 유치 효과 부족
- **선택하지 않은 이유**: 즉시 할인 효과 없음

### 4. 통합 크레딧 시스템
- **장점**: 단일 시스템으로 관리 편의성
- **단점**: 유연한 마케팅 정책 적용 어려움
- **선택하지 않은 이유**: 다양한 할인 정책 지원 부족
