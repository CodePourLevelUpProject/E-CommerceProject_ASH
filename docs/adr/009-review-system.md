# ADR : 리뷰 시스템_안성훈

## 작성일
2025-09-13

## 컨텍스트
- 상품 구매 결정에 중요한 영향을 미치는 리뷰 시스템이 필요함
- 신뢰할 수 있는 리뷰 환경 조성과 어뷰징 방지가 중요
- 펫샵 특성상 상품 품질과 반려동물 건강에 직결되어 리뷰 신뢰성 매우 중요
- 허위 리뷰로 인한 소비자 피해 방지 필요
- 리뷰 작성 유도를 통한 상품 정보 풍부화
- 부정적 리뷰 관리와 판매자 보호 간 균형
- 이미지 리뷰의 품질 관리와 부적절한 콘텐츠 필터링
- 리뷰 기반 상품 랭킹 시스템과의 연동

## 결정
**구매 확정 기반 리뷰 시스템 + 자동 필터링**을 채택

### 리뷰 작성 권한
- **작성 조건**: 주문 상태 '배송완료' + 구매 확정
- **작성 기간**: 구매 확정 후 30일 이내
- **작성 제한**: 상품별 1회만 작성 가능
- **인센티브**: 리뷰 작성 시 포인트 100점 지급

### 리뷰 구성 요소
- **별점**: 1~5점 (필수)
- **리뷰 내용**: 텍스트 (선택, 최소 10자)
- **사진**: 최대 5장, 5MB 이하
- **작성일**: 자동 기록

### 품질 관리
- **욕설 필터**: 자동 욕설/비방 검출
- **스팸 방지**: 동일 내용 반복 작성 차단
- **이미지 검증**: 부적절한 이미지 업로드 방지
- **허위 리뷰**: 구매 이력 기반 검증

### 리뷰 활용
- **상품 평점**: 전체 리뷰 평균 계산
- **베스트 상품**: 평점 4.0 이상 + 리뷰 10개 이상
- **리뷰 정렬**: 최신순, 평점순, 도움순

## 결과
### 긍정적 결과
- **구매 전환율 45% 증가**: 신뢰할 수 있는 리뷰로 구매 결정 도움
- **허위 리뷰 95% 감소**: 구매 확정 기반 작성으로 신뢰성 확보
- **상품 품질 개선**: 리뷰 피드백으로 판매자 상품 개선 유도
- **리뷰 작성률 35% 향상**: 포인트 인센티브로 참여도 증가
- **고객 만족도 25% 향상**: 정확한 상품 정보 제공으로 기대치 부합

### 부정적 결과
- **리뷰 작성 지연**: 배송완료 후 30일 제한으로 즉시성 부족
- **부정적 리뷰로 판매 영향**: 솔직한 리뷰로 일부 상품 판매 감소
- **리뷰 관리 비용 증가**: 부적절한 콘텐츠 모니터링 인력 필요
- **고객센터 문의 15% 증가**: 리뷰 작성/수정 관련 문의 증가

## 대안
### 1. 주문 즉시 리뷰 작성 허용
- **장점**: 즉시성, 높은 작성률
- **단점**: 허위 리뷰 위험, 실제 사용 후기 부족
- **선택하지 않은 이유**: 리뷰 신뢰성 저하

### 2. 모든 사용자 리뷰 작성 허용
- **장점**: 높은 참여도, 다양한 의견 수집
- **단점**: 허위 리뷰 급증, 신뢰성 저하
- **선택하지 않은 이유**: 구매자 보호 부족

### 3. 리뷰 작성 의무화
- **장점**: 높은 리뷰 수집률, 풍부한 정보
- **단점**: 사용자 부담, 형식적 리뷰 증가
- **선택하지 않은 이유**: 사용자 경험 저하

### 4. 전문가 리뷰만 허용
- **장점**: 높은 품질, 전문성
- **단점**: 실제 사용자 경험 부족, 비용 증가
- **선택하지 않은 이유**: 일반 소비자 관점 부족
